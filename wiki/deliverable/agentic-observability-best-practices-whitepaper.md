# Overview
This deliverable is a proposed vendor-neutral white paper establishing best practices for agentic observability. It aims to cover topics such as trace verifiability, attestation, and the use of existing standards like W3C Trace Context and OpenTelemetry [^evt-wg-observability-and-traceability-file-1aa033245d2c-23b44e94].

The working group intends for this document to serve as a design aesthetic paper, potentially leading to submission to the IETF as an RFC, with an initial deadline targeted around late October/early November [^evt-wg-observability-and-traceability-file-1aa033245d2c-23b44e94].

# Architecture / Specification
The paper is intended to focus on currently available solutions and implementation approaches rather than documentation of future concepts. It seeks to address observability across various hyperscalers (GCP, AWS) and platforms (OpenStack). Key areas identified for inclusion relate to security and compliance, cost management, network architecture, and agent design [^evt-wg-observability-and-traceability-file-1aa033245d2c-23b44e94].

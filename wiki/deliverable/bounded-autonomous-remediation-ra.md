# Overview

This reference architecture defines a pattern for resolving a single, bounded [taxonomy/business-task](../taxonomy/business-task.md) autonomously using a sequence of independent [taxonomy/activity](../taxonomy/activity.md) subunits [^evt-wg-workflows-and-process-integration-pr-49]. The architecture emphasizes clear boundaries, defined scope, and explicit recovery mechanisms.

# Architecture / Specification

Terminology alignment mandates the use of 'activity' for workflow subunits and 'business task' for the bounded business problem admitted to and handled by a run [^evt-wg-workflows-and-process-integration-pr-49].

# Overview
This deliverable converts the guidance provided in the [Agentic AI Security Best Practices Guide](../deliverable/agentic-ai-security-best-practices-guide.md) into a format usable by static analysis tools. This aims to provide a code-facing implementation of the security best practices, complementing the document itself [^evt-wg-security-and-privacy-file-5d17bf85b2af-7c215d2d].

The work involves reviewing major SDKs (Google, Amazon, Microsoft) for comparison and conversion [^evt-wg-security-and-privacy-file-5d17bf85b2af-7c215d2d].

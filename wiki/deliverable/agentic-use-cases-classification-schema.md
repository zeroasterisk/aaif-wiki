# Overview
A classification schema and empirical inventory framework developed by the Workflows & Process Integration Working Group to evaluate and categorize production agentic workflows across complexity tiers, coordination modes, and human oversight topologies[^evt-wg-workflows-and-process-integration-pr-41].

# Architecture / Specification
The framework establishes explicit categorization dimensions and strict evidentiary thresholds for cataloging real-world deployments[^evt-wg-workflows-and-process-integration-pr-41]:
- **Evidentiary Standard**: Requires vendor primary documentation or confirmed customer deployment announcements (excluding secondary blogs, analyst commentary, and unverified preprints) to maintain empirical rigor[^evt-wg-workflows-and-process-integration-pr-41].
- **Classification Criteria**: Standardizes fields across coordination topology, human-in-the-loop (HITL) patterns, approval gate subtypes, and single- vs multi-agent rationale[^evt-wg-workflows-and-process-integration-pr-41].
- **Gaps and Mitigations**: Formally identifies source rot and documentation obsolescence within schema governance[^evt-wg-workflows-and-process-integration-pr-41].

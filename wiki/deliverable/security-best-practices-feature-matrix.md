# Overview
This deliverable is a feature matrix designed to map specific security best practices to the required features necessary to support them [^evt-wg-security-and-privacy-pr-20].

# Architecture / Specification
The matrix classifies required features into three categories:
1. **People:** Indicates a need for skills, training, knowledge, and security awareness for all personnel.
2. **Process:** Indicates the feature requires a documented policy, procedure, or formal strategy for how security is executed.
3. **Technology:** Indicates the feature is either physical or digital tools, hardware, software, or automated systems used to enforce security controls [^evt-wg-security-and-privacy-pr-20].

# Overview
This catalog collects reusable design patterns and anti-patterns for building secure and private agentic AI systems. The catalog includes patterns addressing secure memory, execution isolation, and agent control mechanisms like kill-switches [^evt-wg-security-and-privacy-file-5d17bf85b2af-7c215d2d].

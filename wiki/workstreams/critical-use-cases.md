# Overview
The Critical Use Cases workstream operates under the [Workflows & Process Integration Working Group](../working-groups/workflows-and-process-integration.md) to identify, categorize, and document reusable workflow patterns from real-world, deployed agentic AI applications [^evt-wg-workflows-and-process-integration-pr-46]. The workstream prioritizes empirical verification over speculative architecture by indexing real deployments against shared taxonomy schemas [^evt-wg-workflows-and-process-integration-pr-46].

# Architecture / Specification
The workstream maintains two core artifacts [^evt-wg-workflows-and-process-integration-pr-46]:
- `schema-agentic-use-cases.md`: The standardized metadata schema and classification taxonomy used to evaluate agent workflows.
- `use-case-inventory.md`: The inventory of real-world use cases mapped to workflow patterns and classification tags.

### Evidentiary Citation Standards
To ensure all cataloged use cases reflect genuine production systems, the workstream enforces tiered citation requirements [^evt-wg-workflows-and-process-integration-pr-46]:
- **Verification Threshold**: Each inventory entry must cite at least one primary source confirming production deployment, targeting three verified citations per use case [^evt-wg-workflows-and-process-integration-pr-46].
- **Source Tiers**: Classifies source credibility across preferred (primary vendor product pages, confirmed production engineering posts), acceptable, and non-acceptable tiers [^evt-wg-workflows-and-process-integration-pr-46].

# Lifecycle History
The category groupings, metadata schema, and evidentiary rules are prepared for working group approval, while individual inventory rows undergo continuous citation verification [^evt-wg-workflows-and-process-integration-pr-46].

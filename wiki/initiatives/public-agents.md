# Overview
The Public Agents initiative provides an open repository for hosting and distributing public, reusable agent capabilities.[^evt-public-agents-pr-2] The repository serves as an ecosystem hub for modular agent components aligned with Foundation specifications.

# Architecture / Specification
The active repository layout is structured around standalone agent capabilities conformant to the [Agent Skill specification](../specification/agent-skill.md):[^evt-public-agents-pr-2]

- `skills/`: Contains portable agent skill bundles containing instructions, execution scripts, and reference assets.

While preliminary drafts described directories for recipes, prompts, and documentation, active repository contents are limited exclusively to skills.[^evt-public-agents-pr-2]

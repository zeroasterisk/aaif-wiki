# Overview
The Single-Agent Workflow Reference Architecture (SAW-RA) Documentation Blueprint establishes the standardized structural framework for documenting single-agent workflow reference architectures within the Workflows and Process Integration Working Group [^evt-wg-workflows-and-process-integration-file-4196f7be533b-30a5187b].

# Architecture / Specification
The blueprint divides reference architecture documentation into six core sections [^evt-wg-workflows-and-process-integration-file-4196f7be533b-30a5187b]:
1. **Foundations**: Scope, boundaries, core terminology, design principles, and architectural invariants [^evt-wg-workflows-and-process-integration-file-4196f7be533b-30a5187b].
2. **Architecture Model**: Reference models, primitive catalogs, runtime execution components, and composition rules [^evt-wg-workflows-and-process-integration-file-4196f7be533b-30a5187b].
3. **Patterns and Selection**: Pattern taxonomy, selection heuristics, and a reusable pattern catalog [^evt-wg-workflows-and-process-integration-file-4196f7be533b-30a5187b].
4. **Enterprise Readiness**: Enterprise control overlays, security postures, and readiness criteria [^evt-wg-workflows-and-process-integration-file-4196f7be533b-30a5187b].
5. **Workflow Lifecycle**: End-to-end guidance spanning workflow design, assessment, testing, operations, and conformance [^evt-wg-workflows-and-process-integration-file-4196f7be533b-30a5187b].
6. **Evolution and Supporting Material**: Roadmap, migration strategies, and technical appendices [^evt-wg-workflows-and-process-integration-file-4196f7be533b-30a5187b].

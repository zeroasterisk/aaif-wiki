# Overview
The AAIF Technical Committee (TC) is the governing technical body of the Agentic AI Foundation, responsible for overseeing technical standards, best practices, foundation-wide technical vision, working group lifecycle, and project intake [^evt-technical-committee-file-b33563055168-688b7092]. The founding TC members were appointed by the AAIF Governing Board for a term spanning March 1, 2026 through December 31, 2026 [^evt-technical-committee-file-b33563055168-688b7092].

# Architecture / Specification
## Membership and Leadership
The Technical Committee is led by Chair David Soria Parra (Anthropic) and Co-Chair Caitie McCaffrey (Microsoft) [^evt-technical-committee-file-b33563055168-688b7092]. Its appointed members include:
- Alan Blount (Google)
- Bradley Axen (Block)
- James Ward (Amazon Web Services)
- Nick Cooper (OpenAI)
- Sambhav Kothari (Bloomberg)
- Steve Faulkner (Cloudflare) [^evt-technical-committee-file-b33563055168-688b7092]

## Project Lifecycle Oversight
The TC oversees foundation projects across their lifecycle stages as defined in the [Project Lifecycle Policy](../policies/project-lifecycle-policy.md) and [Project Proposal Process](../policies/project-proposal-process.md). Current Impact Stage projects under TC oversight include:
- **Model Context Protocol (MCP)**: Open protocol enabling integration between LLM applications and external data sources or tools [^evt-technical-committee-file-b33563055168-688b7092].
- **goose**: Open-source, extensible AI agent runtime operating across LLMs to install, execute, edit, and test workflows [^evt-technical-committee-file-b33563055168-688b7092].
- **AGENTS.MD**: Standardized context and instruction specification for AI coding agents and development workflows [^evt-technical-committee-file-b33563055168-688b7092].

# Lifecycle History
The TC charter and initial roster were formally established following foundation launch, with all founding members appointed by the Governing Board for the initial 2026 operating term [^evt-technical-committee-file-b33563055168-688b7092].

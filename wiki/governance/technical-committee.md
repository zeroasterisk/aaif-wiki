# Overview
The Technical Committee (TC) is the technical governing body of the Agentic AI Foundation (AAIF), overseeing technical standards, project lifecycles, and foundation-wide architectural direction [^evt-technical-committee-file-b33563055168-688b7092].

# Architecture / Specification
The TC manages project lifecycle intake, establishes working group guidelines, and evaluates projects advancing through Sandbox, Growth, and Impact stages [^evt-technical-committee-file-b33563055168-688b7092].

## Foundation Projects
Key projects hosted at the Impact Stage under TC oversight include [^evt-technical-committee-file-b33563055168-688b7092]:
- **Model Context Protocol (MCP)**: An open protocol enabling integration between LLMs and external data sources and tools.
- **goose**: An extensible open source AI agent runtime.
- **AGENTS.MD**: Standardized repository instruction format for AI agents.

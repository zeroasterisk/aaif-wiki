# Overview
The AAIF Technical Committee (TC) is the technical governing body of the Agentic AI Foundation, responsible for overseeing technical standards, best practices, and the technical vision of the Foundation [^evt-technical-committee-file-b33563055168-688b7092]. Founding TC members were appointed by the AAIF Governing Board for a term running from March 1, 2026 to December 31, 2026 [^evt-technical-committee-file-b33563055168-688b7092].

# Architecture / Specification
## Committee Leadership and Membership
The Technical Committee consists of appointed representatives across industry member organizations [^evt-technical-committee-file-b33563055168-688b7092]:
- **Chair:** David Soria Parra (Anthropic)
- **Co-Chair:** Caitie McCaffrey (Microsoft)
- **Members:** Alan Blount (Google), Bradley Axen (Block), James Ward (Amazon Web Services), Nick Cooper (OpenAI), Sambhav Kothari (Bloomberg), and Steve Faulkner (Cloudflare) [^evt-technical-committee-file-b33563055168-688b7092].

## Project Oversight
The TC evaluates and oversees foundation projects across maturity stages defined in the [project lifecycle policy](../governance/project-lifecycle-policy.md), including Impact Stage initiatives [^evt-technical-committee-file-b33563055168-688b7092]:
- **Model Context Protocol (MCP):** Open protocol standardizing integration between LLM applications and external data sources and tools [^evt-technical-committee-file-b33563055168-688b7092].
- **goose:** Extensible, open-source AI agent framework for multi-LLM tool execution, code editing, and testing [^evt-technical-committee-file-b33563055168-688b7092].
- **AGENTS.MD:** Standardized repository specification and guidance for agent workflows [^evt-technical-committee-file-b33563055168-688b7092].

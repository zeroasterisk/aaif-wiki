# Overview

The AAIF Technical Committee (TC) is the technical governing body of the Agentic AI Foundation, tasked with overseeing technical standards, best practices, project lifecycles, and technical vision across foundation initiatives [^evt-technical-committee-file-b33563055168-688b7092].

# Architecture / Specification

## Committee Membership and Leadership

## Hosted Projects

The TC oversees foundation projects spanning all lifecycle stages defined in [Project Lifecycle Policy](../governance/project-lifecycle-policy.md) [^evt-technical-committee-file-b33563055168-688b7092]:

- **Model Context Protocol (MCP)** (*Impact Stage*): Open protocol enabling LLM applications to integrate with external data sources and tools.
- **Goose** (*Impact Stage*): Extensible open-source AI agent runtime executing multi-turn tool commands and local edits.
- **AGENTS.MD** (*Impact Stage*): Standardized format for declaring agent skills, constraints, and operational metadata.

# Overview
The Technical Committee (TC) is the technical governing body of the Agentic AI Foundation (AAIF), responsible for setting technical direction, overseeing working groups, and managing project lifecycle admissions across Sandbox, Growth, and Impact stages [^evt-technical-committee-file-b33563055168-688b7092].

# Architecture / Specification

## Managed Projects and Working Groups
The TC provides technical oversight and reviews project stage progressions under the [Project Lifecycle Policy](../policies/project-lifecycle-policy.md) [^evt-technical-committee-file-b33563055168-688b7092]. Impact Stage projects hosted under the foundation include:
- **Model Context Protocol (MCP)**: An open protocol enabling seamless integration between LLM applications, external data sources, and tools.
- **[goose](../resources/goose.md)**: An open-source extensible AI agent framework for multi-turn execution and tool use.
- **AGENTS.MD**: An open standard for repository-level agent instruction files.

The TC also evaluates proposals submitted under the [Project Proposal Process](../policies/project-proposal-process.md) and charters working groups following the [Working Group Submission Guidelines](../guidelines/working-group-submission-guidelines.md).

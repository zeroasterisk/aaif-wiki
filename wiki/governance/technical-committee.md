# Overview
The AAIF Technical Committee (TC) serves as the primary technical governing body of the Agentic AI Foundation, responsible for overseeing technical standards, best practices, and the overarching technical vision across the foundation [^evt-technical-committee-file-b33563055168-688b7092]. The TC operates under the Technical Charter established by the AAIF Governing Board and oversees foundation working groups, review procedures, and project lifecycle transitions [^evt-technical-committee-file-b33563055168-688b7092].

## Project Oversight and Stages
The TC evaluates candidate and hosted projects against the [Project Lifecycle](../governance/project-lifecycle.md) criteria. Flagship projects accepted into the foundation's Impact Stage include:
- **Model Context Protocol (MCP)**: Open protocol enabling seamless integration between LLM applications, external data sources, and tools [^evt-technical-committee-file-b33563055168-688b7092].
- **goose**: Open-source, extensible AI agent runtime executing and testing tasks across arbitrary LLMs [^evt-technical-committee-file-b33563055168-688b7092].
- **AGENTS.MD**: Specification and convention tooling for agent context and runtime discovery [^evt-technical-committee-file-b33563055168-688b7092].

# Overview
The Working Group Submission Guidelines govern the formation of new Working Groups (WGs) within the Agentic AI Foundation (AAIF) [^evt-working-group-proposals-file-b33563055168-33233981]. Proposals are tracked publicly, reviewed by the Technical Committee (TC), and require both Technical Committee and Governing Board approval to launch.

# Architecture / Specification
## Application and Intake Workflow
1. **Submission**: Proposers open a Working Group Proposal Application issue on GitHub using the standardized issue template [^evt-working-group-proposals-file-b33563055168-33233981].
2. **Tracking**: New submissions are added to the backlog on the Working Group Proposals project board for triage [^evt-working-group-proposals-file-b33563055168-33233981].
3. **Review**: Proposals are scheduled for evaluation during upcoming [Technical Committee](../governance/technical-committee.md) meetings [^evt-working-group-proposals-file-b33563055168-33233981].

## Status Lifecycle Labels
- `New`: The proposal is newly submitted and queued in the backlog [^evt-working-group-proposals-file-b33563055168-33233981].
- `Waiting on Comment`: Reviewers have requested clarifications or additional details via issue comments [^evt-working-group-proposals-file-b33563055168-33233981].
- `Too Early`: The proposal is deemed premature, with guidance provided for future reapplication [^evt-working-group-proposals-file-b33563055168-33233981].
- `Declined`: The proposal has been rejected, with rationale documented in comments [^evt-working-group-proposals-file-b33563055168-33233981].
- `Approved`: The proposal has been accepted [^evt-working-group-proposals-file-b33563055168-33233981].

## Voting and Approval Thresholds
To be accepted, a working group proposal must receive a simple majority vote of all members of the Technical Committee and remains subject to final approval by the AAIF Governing Board [^evt-working-group-proposals-file-b33563055168-33233981].

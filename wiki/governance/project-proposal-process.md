# Overview

The AAIF Project Proposal Process defines the sequential operating procedure for reviewing, approving, and onboarding project submissions into the Agentic AI Foundation [^evt-technical-committee-file-05a7e66403db-81ecc37a]. It serves as the operational implementation of the [Project Lifecycle Policy](../governance/project-lifecycle-policy.md) [^evt-technical-committee-file-05a7e66403db-81ecc37a].

# Architecture / Specification

The intake and approval pipeline runs primarily asynchronously across six sequential steps and supporting parallel milestones [^evt-technical-committee-file-05a7e66403db-81ecc37a]:

1. **Step 1 - Initial Intake**: The Foundation CTO, assisted by an automated intake agent performing technical compliance checks, screens submissions for completeness and alignment [^evt-technical-committee-file-05a7e66403db-81ecc37a].
2. **Step 2 - TC Q&A Window**: An offline review window where proposals must satisfy a defined Technical Committee engagement bar [^evt-technical-committee-file-05a7e66403db-81ecc37a]. If engagement is unmet, an on-demand TC supporter mechanism is triggered [^evt-technical-committee-file-05a7e66403db-81ecc37a]. Submissions may optionally present live if requested [^evt-technical-committee-file-05a7e66403db-81ecc37a].
3. **Parallel - Contributor Paperwork**: Contributor and IP legal paperwork runs in parallel with technical evaluation [^evt-technical-committee-file-05a7e66403db-81ecc37a].
4. **Step 3 - TC Vote**: The [Technical Committee](../governance/technical-committee.md) votes asynchronously via LFX Vote on admission and initial lifecycle stage [^evt-technical-committee-file-05a7e66403db-81ecc37a].
5. **Step 4 - GB Approval**: The Governing Board confirms organizational readiness and approves entry via LFX Vote [^evt-technical-committee-file-05a7e66403db-81ecc37a].
6. **Step 5 - Legal Formation**: Linux Foundation Legal completes contribution agreements, charter formation, and asset transfers [^evt-technical-committee-file-05a7e66403db-81ecc37a].
7. **Step 6 - Technical Onboarding**: Linux Foundation IT and project submitters execute infrastructure transition and repository onboarding [^evt-technical-committee-file-05a7e66403db-81ecc37a].

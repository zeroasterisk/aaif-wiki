# Overview

The Agentic AI Foundation (AAIF) Project Lifecycle Policy establishes the governance rules and formal processes for open technical projects joining, progressing through, and retiring within the foundation [^evt-technical-committee-file-8f732085cd4f-49330cd0]. Administered by the Technical Committee (TC) under the terms of the AAIF Charter, the policy provides a predictable path for projects across four distinct lifecycle stages: Sandbox, Growth, Impact, and Emeritus [^evt-technical-committee-file-8f732085cd4f-49330cd0].

Progression across lifecycle stages allows projects to participate at maturity levels matched to their governance, community adoption, and technical validation, ensuring access to AAIF mentorship and foundation resources [^evt-technical-committee-file-8f732085cd4f-49330cd0].

# Architecture / Specification

## Project Proposal Process

Projects must apply via the `aaif/project-proposals` repository by submitting a comprehensive intake application [^evt-technical-committee-file-8f732085cd4f-49330cd0]. Key proposal requirements include:
- Project description, origin, use cases, and alignment with the AAIF mission.
- OSI-approved permissive license and public repository location.
- Documented governance model (`GOVERNANCE.md`), core maintainer lists, and public communication channels.
- Release mechanics, automated CI/CD validation, public issue trackers, and external dependency licensing.
- Optional details regarding a Technical Committee sponsor and cross-project integrations.

## Lifecycle Stages

1. **Sandbox Stage**: Entry-level stage for early-stage or experimental projects meeting basic requirements (OSI license, public repo, mission alignment) [^evt-technical-committee-file-8f732085cd4f-49330cd0].
2. **Growth Stage**: Intermediate stage for projects demonstrating active adoption, defined release processes, open governance, and an expanding contributor base [^evt-technical-committee-file-8f732085cd4f-49330cd0].
3. **Impact Stage**: Mature, flagship projects exhibiting high production adoption, robust multi-organizational governance, comprehensive security practices, and proven ecosystem impact [^evt-technical-committee-file-8f732085cd4f-49330cd0].
4. **Emeritus Stage**: End-of-life status for inactive or deprecated projects transitioning away from active development while preserving historical project assets [^evt-technical-committee-file-8f732085cd4f-49330cd0].

## Annual Review Process

The Technical Committee evaluates all active projects annually to assess continued alignment, health metrics, governance vitality, and stage graduation readiness [^evt-technical-committee-file-8f732085cd4f-49330cd0].

# Overview

The Cross-Working Group Security and Privacy Review Checklist workstream defines a lightweight review framework and verification checklist to help peer AAIF working groups identify and address security and privacy risks in their specifications and architectures [^evt-wg-security-and-privacy-file-fa4050a9f626-fb1414ed, ^evt-wg-security-and-privacy-file-75f22d914368-03de91f5].

# Architecture / Specification

- **Lead Contributor**: Govindaraj Palanisamy [^evt-wg-security-and-privacy-file-fa4050a9f626-fb1414ed].
- **Objectives**: Establish cross-functional review criteria covering threat analysis, identity delegation, data isolation, and auditable telemetry across all Foundation outputs without blocking workstream velocity [^evt-wg-security-and-privacy-file-fa4050a9f626-fb1414ed, ^evt-wg-security-and-privacy-file-75f22d914368-03de91f5].
- **Inter-Group Coordination**: Conducts a cross-document gap analysis with other AAIF working groups to prevent overlapping mandates and align security review touchpoints [^evt-wg-security-and-privacy-file-75f22d914368-03de91f5].

# Lifecycle History

# Overview
The Workflows & Process Integration Working Group is an Agentic AI Foundation technical governance body established to standardize workflow execution models, activity schemas, coordination patterns, and runtime control interfaces across heterogeneous AI agent systems [^evt-wg-workflows-and-process-integration-file-5028db4c24a1-b054a303].

# Architecture / Specification
The working group directs multiple workstreams and architectural deliverables:
- **Critical Use Cases**: Maintains a verified cross-industry inventory of production agent deployments and a five-dimensional structural classification schema ([Critical Use Cases Workstream](../workstreams/critical-use-cases.md)) [^evt-wg-workflows-and-process-integration-file-5028db4c24a1-b054a303][^evt-wg-workflows-and-process-integration-file-6cdd0fb97084-5ba45ebc].
- **Execution Semantics & Vocabularies**: Standardizes foundational workflow definitions, lifecycle boundaries, and activity contracts (see [Core Workflow Terms](../taxonomy/core-workflow-terms.md) and [Workflow Architecture Principles](../policies-guidelines/workflow-architecture-principles.md)).
- **Pattern Catalog**: Defines architectural patterns for reliable agent execution, including [Bounded Convergence Loop](../patterns/bounded-convergence-loop.md), [Deterministic Acceptance Gate](../patterns/deterministic-acceptance-gate.md), and [Proposal-Execution Split](../patterns/proposal-execution-split.md).

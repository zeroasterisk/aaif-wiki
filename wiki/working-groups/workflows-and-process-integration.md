# Overview
The Workflows and Process Integration Working Group is an Agentic AI Foundation (AAIF) technical body responsible for defining shared workflow models, common execution primitives, reference architectures, and design patterns for agentic orchestration.[^evt-wg-workflows-and-process-integration-file-fa4050a9f626-89594a26]

# Architecture / Specification
The working group structures its core technical initiatives across three primary workstreams:[^evt-wg-workflows-and-process-integration-file-fa4050a9f626-89594a26]
- **Reference Architectures**: Defines 7 execution profiles spanning from fully deterministic (Profile 1) to fully agentic (Profile 7), formulates the "least agentic default" principle, and demonstrates a specification-driven design flow that compiles machine-readable YAML specs into architectural diagrams and documentation across charter-derived archetypes.[^evt-wg-workflows-and-process-integration-file-fa4050a9f626-89594a26]
- **Critical Use Cases**: Analyzes practitioner use cases (categorizing 89 industry scenarios) across core primitives (triggers, human-in-the-loop patterns, agent counts, and coordination methods) distilled into a concise pattern catalog including the [Bounded Convergence Loop](../patterns/bounded-convergence-loop.md).[^evt-wg-workflows-and-process-integration-file-fa4050a9f626-89594a26]
- **Taxonomy Alignment**: Coordinates with the cross-WG [Taxonomy and Landscape](../initiatives/taxonomy-and-landscape.md) workstream to align execution primitives, machine-readable short codes, and universal agent terminology.[^evt-wg-workflows-and-process-integration-file-fa4050a9f626-89594a26]

# Lifecycle History
In July 2026, the working group validated its specification-driven architecture approach across representative invoice processing and autonomous maintenance use cases and staged foundational pattern and taxonomy proposals for formal adoption.[^evt-wg-workflows-and-process-integration-file-fa4050a9f626-89594a26]

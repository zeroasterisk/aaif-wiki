# Overview
The Agent Context and Memory Working Group is a proposed AAIF technical working group established to develop vendor-neutral standards, reference architectures, and lifecycle semantics for how agents acquire, organize, retrieve, retain, and share context and memory[^evt-working-group-proposals-issue-5]. Chaired by Stephen Chin (Neo4j), the group addresses interoperability challenges spanning context graphs, knowledge graphs, vector retrieval indexes, and episodic memory stores[^evt-working-group-proposals-issue-5].

# Architecture / Specification
The working group proposal identifies key technical focus areas across agent memory architectures[^evt-working-group-proposals-issue-5]:
- **Memory Models and Representation**: Standardizing data structures for working, episodic, semantic, and procedural memory across graph, vector, relational, and document stores[^evt-working-group-proposals-issue-5].
- **Context Management**: Formulating patterns and best practices for context retrieval, ranking, assembly, summarization, compression, caching, and token budgeting[^evt-working-group-proposals-issue-5].
- **Lifecycle and Security Semantics**: Establishing rules for memory retention, eviction, cross-session sharing, and privacy controls[^evt-working-group-proposals-issue-5].
- **Benchmarking and Evaluation**: Creating evaluation methodologies to measure memory recall quality, execution latency, cost, and task completion impacts[^evt-working-group-proposals-issue-5].

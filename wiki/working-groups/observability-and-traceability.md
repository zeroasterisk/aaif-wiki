# Overview

The Observability and Traceability Working Group establishes vendor-neutral standards, semantic conventions, reference architectures, and open specifications for monitoring agentic AI systems. The group coordinates telemetry models spanning agent-tool boundaries, execution graphs, and behavioral tracing across multi-agent workflows.

# Architecture / Specification

## Core Deliverables & Workstreams

- **Agent Behavior Trace Model**: Standardizing execution state capture, context, and reasoning telemetry, targeting initial reference implementations aligned with W3C Trace Context and OpenTelemetry specifications [^evt-wg-observability-and-traceability-file-1aa033245d2c-23b44e94].
- **Agentic Observability Best Practices White Paper**: Formulating cross-industry best practices covering trace verifiability, attestation, cost management, security/compliance, and agent context tracking in collaboration with industry practitioners [^evt-wg-observability-and-traceability-file-1aa033245d2c-23b44e94].
- **Taxonomy Alignment**: Curating standardized vocabulary terms for agent telemetry and observability in coordination with the [Taxonomy and Landscape Workstream](../working-groups/taxonomy-and-landscape.md) [^evt-wg-observability-and-traceability-file-1aa033245d2c-23b44e94].
- **External Specifications Collaboration**: Exploring federation, resource discovery, and trace interoperability with projects such as Agent Resource Discovery (ARD) and standards organizations including the IETF [^evt-wg-observability-and-traceability-file-1aa033245d2c-23b44e94].

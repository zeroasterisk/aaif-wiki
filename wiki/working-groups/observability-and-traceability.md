# Overview
The Observability and Traceability Working Group is an Agentic AI Foundation (AAIF) technical working group developing open telemetry standards, distributed trace models, semantic conventions, and audit record specifications for autonomous agent executions.[^evt-wg-observability-and-traceability-pr-56]

# Architecture / Specification
The working group focuses on core observability and auditability specifications, including:
- **Telemetry and Trace Models**: Standardizing execution context propagation, causal linking across tool invocations, and semantic conventions in alignment with [OpenTelemetry](../reference-architectures/opentelemetry.md).[^evt-wg-observability-and-traceability-pr-56]
- **Evidence Records and Verification**: Defining testable data models for tamper-evident execution logs, disambiguating evidence-grade ladder classifications (such as grades E1 through E4) from use case identifiers, and decoupling RFC 3161 technical timestamping properties from jurisdictional legal weight and relying-party regimes.[^evt-wg-observability-and-traceability-pr-56]
- **Cross-Cutting Telemetry Requirements**: Specifying boundary observations, gateway recording obligations, and verifiable execution trails across heterogeneous runtime environments.[^evt-wg-observability-and-traceability-pr-56]

# Lifecycle History
The working group actively refines its use cases register and evidence requirements, addressing identifier collisions and distinguishing technical evidence integrity from legal liability frameworks.[^evt-wg-observability-and-traceability-pr-56]

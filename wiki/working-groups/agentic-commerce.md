# Overview

The Agentic Commerce Working Group is an AAIF technical body tasked with standardizing protocol interoperability, transaction governance, identity mandates, and financial interaction boundaries for agent-led commerce[^evt-wg-agentic-commerce-pr-9]. Its scope spans agent-mediated checkout workflows, machine-to-machine payments, and verifiable consumer intent delegation.

# Architecture / Specification

The working group evaluates emerging protocols against agentic transaction lifecycles, identifying handoffs and capability boundaries across:

- **onX**: Specifications governing verifiable merchant interaction and transaction framing[^evt-wg-agentic-commerce-pr-9].
- **Machine Payments Protocol (MPP)**: Autonomous agent settlement and machine-to-machine financial transfer frameworks[^evt-wg-agentic-commerce-pr-9].
- **Universal Commerce Protocol (UCP)**: Shared interoperability primitives standardizing catalog discovery, checkout handoffs, and consumer mandate verification[^evt-wg-agentic-commerce-pr-9].

Each protocol is analyzed along four dimensions: problem formulation, functional mechanics, governance status, and operational handoff boundaries to peer protocols[^evt-wg-agentic-commerce-pr-9].

# Lifecycle History

In September 2026, the working group delivered comparative evaluations of the onX, MPP, and UCP August releases, detailing protocol governance and cross-standard integration touchpoints[^evt-wg-agentic-commerce-pr-9].

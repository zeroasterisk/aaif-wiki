# Overview
The Agentic Commerce Working Group is an AAIF technical body establishing vendor-neutral capability models, protocol evaluations, and transaction standards for autonomous agent interactions [^evt-wg-agentic-commerce-pr-9]. The working group defines foundational architectural patterns for commercial operations, including [Agentic Checkout](../taxonomy/agentic-checkout.md) and [Delegated Payment](../taxonomy/delegated-payment.md).

# Architecture / Specification
The working group evaluates external and emerging commercial agent protocols and coordinates cross-boundary transaction specifications [^evt-wg-agentic-commerce-pr-9].

## Protocol Comparative Analyses
Through its recurring technical reviews and monthly deliverables, the working group conducts comparative deep dives into autonomous commerce specifications, focusing on onX, Merchant Payment Protocol (MPP), and Universal Commerce Protocol (UCP) [^evt-wg-agentic-commerce-pr-9]. Reviews analyze each protocol through four structural criteria:
- **Problem Domain:** The specific commercial friction, cart abstraction, or payment coordination challenge addressed [^evt-wg-agentic-commerce-pr-9].
- **Runtime Mechanics:** Operational execution mechanisms, messaging flows, and state synchronization across agent boundaries [^evt-wg-agentic-commerce-pr-9].
- **Governance and Status:** Standardization stage, release lifecycles, and open governance structures [^evt-wg-agentic-commerce-pr-9].
- **Inter-Protocol Handoffs:** Integration demarcations where individual protocols transition responsibilities to peer transaction layers [^evt-wg-agentic-commerce-pr-9].

# Overview
The Agentic Commerce Working Group is an AAIF technical body focused on defining standardized interaction models, capability maps, and transaction lifecycle handoffs for AI agents conducting commercial activities [^evt-ws-taxonomy-landscape-pr-73]. The group collaborates across AAIF workstreams to establish standard terminology and governance boundaries for autonomous purchasing, delegated financial commitments, and customer-merchant handoffs [^evt-ws-taxonomy-landscape-pr-73, ^evt-ws-taxonomy-landscape-pr-76, ^evt-ws-taxonomy-landscape-pr-77].

# Architecture / Specification
The working group standardizes commercial primitives within the foundation taxonomy [^evt-ws-taxonomy-landscape-pr-73, ^evt-ws-taxonomy-landscape-pr-76, ^evt-ws-taxonomy-landscape-pr-77]:
- **Agentic Checkout**: Formalized in the domain taxonomy to define the automated protocol stages through which an agent navigates cart assembly, pricing verification, merchant fulfillment terms, and checkout closure [^evt-ws-taxonomy-landscape-pr-73].
- **Delegated Payment**: Architectural boundary enabling a principal (human or organization) to securely delegate payment execution authority to an agent within strict budget, token, or cryptographic limits [^evt-ws-taxonomy-landscape-pr-76].
- **Mandate**: Explicit, verifiable authorization artifact defining the allowable scope, expiration, spending limits, and vendor parameters under which an agent is empowered to transact on behalf of a user [^evt-ws-taxonomy-landscape-pr-77].

# Lifecycle History
The working group's foundational vocabulary was integrated into the AAIF landscape and taxonomy registry via formal pull requests to establish vendor-neutral commercial standards across member organizations [^evt-ws-taxonomy-landscape-pr-73, ^evt-ws-taxonomy-landscape-pr-76, ^evt-ws-taxonomy-landscape-pr-77].

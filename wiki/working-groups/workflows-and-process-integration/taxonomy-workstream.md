# Overview

The Taxonomy Workstream is an internal initiative of the [Workflows and Process Integration Working Group](../workflows-and-process-integration.md). Its primary goal is to establish a shared vocabulary for the WG to reduce ambiguity across specifications, reference architectures, and use case documentation produced by the group [^evt-wg-workflows-and-process-integration-file-84f82d5fdbae-2bafe01a].

The initial set of core workflow terms has been proposed and is currently under review [^evt-wg-workflows-and-process-integration-file-84f82d5fdbae-2bafe01a] [^evt-wg-workflows-and-process-integration-pr-25]. Terms are subject to change as WG discussions progress [^evt-wg-workflows-and-process-integration-file-84f82d5fdbae-2bafe01a].

# Related Workstreams

The terms defined by this workstream are applied in related WG initiatives, including Reference Architectures and Critical Use Cases [^evt-wg-workflows-and-process-integration-file-84f82d5fdbae-2bafe01a].

# Overview

The DIF Trusted AI Agents Working Group is a decentralized identity initiative stewarded by the Decentralized Identity Foundation (DIF)[^evt-ext-frmoretto-agentic-standards-map-85d122-file-1837116489b7-e12907fb]. The working group defines an interoperable stack to enable trustworthy, privacy-preserving, and secure autonomous agents using Decentralized Identifiers (DIDs) and Verifiable Credentials (VCs)[^evt-ext-frmoretto-agentic-standards-map-85d122-file-1837116489b7-e12907fb].

Related communication protocols include the [Agent Network Protocol](../standards/agent-network-protocol.md).

# Architecture / Specification

The working group structures its technical deliverables across specialized task forces[^evt-ext-frmoretto-agentic-standards-map-85d122-file-1837116489b7-e12907fb]:
- **Delegated Authority Task Force**: Specifies data schemas and cryptographic verification flows for asserting bounded authority granted by human principals or parent organizations to autonomous agents[^evt-ext-frmoretto-agentic-standards-map-85d122-file-1837116489b7-e12907fb].
- **KYA-OS Task Force**: Develops 'Know Your Agent' operational software and standards for agent verification and provenance, built around the open-source KYA-OS codebase[^evt-ext-frmoretto-agentic-standards-map-85d122-file-1837116489b7-e12907fb].
- **Scope Boundaries**: The working group focuses on identity, delegation, and security primitives; commercial discovery, product catalog indexing, and merchant transaction flows are not part of its scope[^evt-ext-frmoretto-agentic-standards-map-85d122-file-1837116489b7-e12907fb].

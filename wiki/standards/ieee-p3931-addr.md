# Overview
IEEE P3931 is an interoperability standardization project stewarded by the IEEE Standards Association (IEEE SA) entitled Agent Description, Discovery, and Registry (ADDR) Interoperability [^evt-ext-frmoretto-agentic-standards-map-85d122-file-f3f5b3af6d2f-0261b283]. It specifies metadata models and discovery protocols for intelligent agents operating across platforms, organizations, and ecosystems [^evt-ext-frmoretto-agentic-standards-map-85d122-file-f3f5b3af6d2f-0261b283].

Within the broader agent discovery landscape, IEEE P3931 overlaps with discovery initiatives including IETF DAWN (`../standards/ietf-dawn.md`), Agentic Resource Discovery (`../standards/agentic-resource-discovery.md`), AI Catalog (`../standards/ai-catalog.md`), and Agent-to-Agent discovery interfaces (`../standards/a2a.md`).

# Architecture / Specification
According to the approved Project Authorization Request (PAR), IEEE P3931 defines [^evt-ext-frmoretto-agentic-standards-map-85d122-file-f3f5b3af6d2f-0261b283]:
- **Agent Description Model**: Standardized schemas to describe agent capabilities, interfaces, communication requirements, and operational parameters across organizational boundaries [^evt-ext-frmoretto-agentic-standards-map-85d122-file-f3f5b3af6d2f-0261b283].
- **Registry Mechanisms**: Common specifications for registering, indexing, and updating agent descriptors within federated or local directories [^evt-ext-frmoretto-agentic-standards-map-85d122-file-f3f5b3af6d2f-0261b283].
- **Discovery Protocols**: Query protocols enabling AI agents to search registries and resolve compatible remote agents [^evt-ext-frmoretto-agentic-standards-map-85d122-file-f3f5b3af6d2f-0261b283].
- **Scope Boundary**: The scope explicitly excludes agent identity frameworks, trust scoring systems, collaborative governance policies, and domain-specific business semantics [^evt-ext-frmoretto-agentic-standards-map-85d122-file-f3f5b3af6d2f-0261b283].

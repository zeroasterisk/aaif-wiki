# Overview
The Agentic Web Working Group is a proposed standards working group stewarded by the World Wide Web Consortium (W3C) [^evt-ext-frmoretto-agentic-standards-map-85d122-file-dd53aa169358-d6874b1e]. Its mission is to standardize specifications that enable web pages and web applications to expose structured context and actionable capabilities to language models and AI agents [^evt-ext-frmoretto-agentic-standards-map-85d122-file-dd53aa169358-d6874b1e]. The group's primary planned normative deliverable is [WebMCP](../standards/webmcp.md), transitioning work initiated in the Web Machine Learning Community Group to the W3C Recommendation track [^evt-ext-frmoretto-agentic-standards-map-85d122-file-dd53aa169358-d6874b1e].

# Architecture / Specification
- **Core Focus Areas**: Standardizing web application capability discovery for AI agents, delegation and agent identity primitives, and user-enforceable permissions and policy controls for agent actions [^evt-ext-frmoretto-agentic-standards-map-85d122-file-dd53aa169358-d6874b1e].
- **Normative Deliverables**: Adoption and standardization of WebMCP as a client-side browser API [^evt-ext-frmoretto-agentic-standards-map-85d122-file-dd53aa169358-d6874b1e].
- **Coordination**: Establishes formal coordination points with the Web Payment Security Interest Group, [IETF Web Bot Auth](../standards/ietf-webbotauth.md), and [IETF AIPREF](../standards/ietf-aipref.md) [^evt-ext-frmoretto-agentic-standards-map-85d122-file-dd53aa169358-d6874b1e].
- **Scope Boundaries**: Inference execution, foundation model APIs, cryptographic authentication primitives, crawler exclusion controls, and direct agent-to-server communications are excluded from scope [^evt-ext-frmoretto-agentic-standards-map-85d122-file-dd53aa169358-d6874b1e].

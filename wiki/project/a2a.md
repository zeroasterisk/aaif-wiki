# Overview

A2A (Agent-to-Agent) is an open agent interoperability layer and AAIF hosted project designed to facilitate standardized communication and coordination across independent AI agent systems [^evt-wg-observability-and-traceability-pr-31].

# Architecture / Specification

- **Signed Agent Cards:** Introduced in A2A v1.0 to declare agent capabilities, trust assertions, and endpoint metadata [^evt-wg-observability-and-traceability-pr-31].
- **Identity Verification:** Provides a standardized verification surface to validate declared agent card claims against observed runtime behavior across network boundaries [^evt-wg-observability-and-traceability-pr-31].

# Lifecycle History

A2A joined the Agentic AI Foundation as a hosted project in August 2026 [^evt-wg-observability-and-traceability-pr-31].

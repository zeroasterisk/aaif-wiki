# Overview

agentgateway is an open-source traffic control and mediation plane for AI agents, governing Model Context Protocol (MCP) and Agent-to-Agent (A2A) network traffic [^evt-wg-observability-and-traceability-pr-31].

# Architecture / Specification

- **Protocol Mediation:** Manages and routes traffic across heterogeneous MCP tool servers and A2A peer networks [^evt-wg-observability-and-traceability-pr-31].
- **Policy Enforcement:** Functions as an enforcement point for access control, rate limiting, telemetry emission, and evidence layer validation [^evt-wg-observability-and-traceability-pr-31].
- **Deployment:** Deployable across cloud marketplaces including AWS, Azure, and GCP [^evt-wg-observability-and-traceability-pr-31].

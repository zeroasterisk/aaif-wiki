# Overview
An execution environment and runtime wrapper managing agent lifecycle, tool execution, context injection, and policy boundary enforcement[^evt-ws-taxonomy-landscape-pr-48].

# Architecture / Specification
A harness provides the direct boundary between an agent core and host operating systems, tools, or memory stores. In multi-agent configurations, individual harnesses may be composed and orchestrated under a [Meta-Harness](../taxonomy/meta-harness.md)[^evt-ws-taxonomy-landscape-pr-48].

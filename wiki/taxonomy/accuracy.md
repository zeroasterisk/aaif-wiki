# Overview
**Accuracy** is the property of an agentic execution whereby a single run produces correct outputs and behavior when evaluated against an explicitly declared correctness criterion.[^evt-ws-taxonomy-landscape-pr-101] Originated by the [Accuracy and Reliability Working Group](../working-groups/accuracy-and-reliability.md) as part of its canonical terminology and taxonomy deliverable, accuracy focuses on individual execution correctness rather than consistency across repeated invocations.[^evt-ws-taxonomy-landscape-pr-101]

In the AAIF taxonomy, accuracy contrasts directly with [reliability](../taxonomy/reliability.md), which assesses the stability of correct results across repeated agent runs and changing environmental conditions.[^evt-ws-taxonomy-landscape-pr-101]

# Architecture / Specification
The taxonomy scope note establishes two primary dimensions of accuracy within an agent execution:[^evt-ws-taxonomy-landscape-pr-101]

- **Outcome Accuracy**: Evaluates whether the final artifact, response, or terminal state generated by the agent satisfies the declared correctness specification.[^evt-ws-taxonomy-landscape-pr-101]
- **Action Accuracy**: Evaluates whether the intermediate tool calls, parameter selections, and protocol interactions executed by the agent follow expected procedures and valid execution constraints.[^evt-ws-taxonomy-landscape-pr-101]

Both dimensions mandate an explicit, observable reference criterion against which correctness is measured, precluding undefined or subjective expectations during evaluation.[^evt-ws-taxonomy-landscape-pr-101]

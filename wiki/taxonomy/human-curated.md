# Overview
Human curated is a classification and quality signal indicating that an artifact, taxonomy entry, dataset, or agent output has been explicitly reviewed and validated by human domain practitioners[^evt-ws-taxonomy-landscape-pr-39].

# Architecture / Specification
The designation provides governance clarity across agentic pipelines by distinguishing automated synthesis from reviewed knowledge bases[^evt-ws-taxonomy-landscape-pr-39]:
- **Assurance Signal**: Serves as a trust boundary indicator within agentic workflows and landscape taxonomies[^evt-ws-taxonomy-landscape-pr-39].
- **Governance Alignment**: Complements human-in-the-loop patterns such as [Single Agent Human Approval Architecture](../deliverable/single-agent-human-approval-architecture.md) and [AI Usage Policy](../governance/ai-usage-policy.md).

# Overview

In the Agentic AI Foundation taxonomy, a Prompt is defined as the input provided to a model to guide its response, reasoning trajectory, or operational behavior [^evt-ws-taxonomy-landscape-pr-84]. Prompts encapsulate instructions, contextual state, system directives, and dynamic tool schemas presented to the underlying inference runtime.

# Vocabulary and Scope

The taxonomy draws an explicit contrast between a prompt and the underlying intent: the prompt represents what the user or orchestrator explicitly directed the model to do, whereas intent represents what they ultimately sought to achieve [^evt-ws-taxonomy-landscape-pr-84]. Within multi-turn agent systems, prompts are continuously composed and augmented by orchestrators incorporating historical turn traces, retrieved memory records, and standardized tool responses [^evt-ws-taxonomy-landscape-pr-84].

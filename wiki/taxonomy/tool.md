# Overview
A tool is an external function, API, or service that an AI agent may call to retrieve data or perform an action[^evt-ws-taxonomy-landscape-pr-87].

# Architecture / Specification
Within the AAIF taxonomy, tools define external capability endpoints available to agents[^evt-ws-taxonomy-landscape-pr-87]:

- **Functional Interface**: Encompasses external APIs, remote procedure calls, local system utilities, and web services callable by an agent runtime.
- **Contrast with Skills**: The taxonomy maintains paired conceptual links contrasting tools (external execution mechanisms and endpoints) with skills (modular procedural instructions, domain guidance, and packaged routines).

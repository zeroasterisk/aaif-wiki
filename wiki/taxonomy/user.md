# Overview

User is a universal taxonomy term defined by the [Taxonomy and Landscape Working Group](../working-groups/taxonomy-and-landscape.md) designating an individual or client entity interacting with a system or interface.[^evt-ws-taxonomy-landscape-pr-96]

# Scope and Disambiguation

The taxonomy clarifies the boundary between different user contexts in agentic systems, distinguishing between the user interacting with an online surface (such as a web form or service) and the user acting as an agent's [principal](../taxonomy/principal.md) directing or configuring agent behavior.[^evt-ws-taxonomy-landscape-pr-96]

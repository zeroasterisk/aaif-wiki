# Overview
A subagent is an agent spawned by an existing agent to execute delegated tasks or sub-workflows [^evt-ws-taxonomy-landscape-pr-68].

# Architecture / Specification
In the Agentic AI Foundation taxonomy curated by the [Taxonomy and Landscape Working Group](../working-groups/taxonomy-and-landscape.md), subagent is categorized as a universal term directly related to the base concept of an agent [^evt-ws-taxonomy-landscape-pr-68].

A subagent relationship is strictly structural; being spawned by another agent does not imply or automatically transfer operational properties, including [^evt-ws-taxonomy-landscape-pr-68]:
- Authentication and identity attribution
- Access control privileges and security boundaries
- Execution environment or sandbox boundaries
- Permission sets and operational scopes

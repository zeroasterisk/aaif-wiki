# Overview

An Activity is a subunit within an agentic workflow, representing a discrete step or operation. It is a component used to compose a larger [taxonomy/business-task](../taxonomy/business-task.md) [^evt-wg-workflows-and-process-integration-pr-49].

This terminology is used to align concepts across reference architectures, such as the [deliverable/bounded-autonomous-remediation-ra](../deliverable/bounded-autonomous-remediation-ra.md).

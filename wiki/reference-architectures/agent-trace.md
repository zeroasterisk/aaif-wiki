# Overview

Agent Trace is an open specification designed to capture line-level code attribution traces generated by AI coding agents within version-controlled repositories [^evt-wg-observability-and-traceability-file-58f77875accc-fcdb4756]. It provides a vendor-neutral format to record which models, sessions, and edit operations produced specific modifications across codebases [^evt-wg-observability-and-traceability-file-58f77875accc-fcdb4756].

# Architecture / Specification

Operating as a local-first telemetry format at the primitive session layer, Agent Trace records file modifications and tool invocations [^evt-wg-observability-and-traceability-file-58f77875accc-fcdb4756]:

- **Hook Dispatches**: Agent environments (such as Cursor and Claude Code) trigger hook events on actions like file edits, tab completions, and shell executions [^evt-wg-observability-and-traceability-file-58f77875accc-fcdb4756].
- **Trace Dispatcher**: Event payloads are piped via stdin JSON to a hook dispatcher script (`trace-hook.ts`) executing on the Bun runtime [^evt-wg-observability-and-traceability-file-58f77875accc-fcdb4756].
- **Persistence**: Trace records are appended directly to local repository storage in `.agent-trace/traces.jsonl`, binding edits to specific file paths, contributor metadata, and revision history without requiring a remote collector [^evt-wg-observability-and-traceability-file-58f77875accc-fcdb4756].

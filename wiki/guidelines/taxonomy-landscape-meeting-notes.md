# Overview

This guideline defines canonical agent instructions and operational procedures for generating and publishing meeting notes in the Taxonomy and Landscape workstream repository [^evt-ws-taxonomy-landscape-file-eb9c68e792e7-e45bd7ea]. It standardizes file naming, cross-linking in the primary index, section retention for empty content, and strict prose tone boundaries.

# Architecture / Specification

### File Naming and Structure

Notes must be saved under `YYYY-MM-DD.md` matching the meeting date [^evt-ws-taxonomy-landscape-file-eb9c68e792e7-e45bd7ea]. Content is generated by instantiating `TEMPLATE.md` with the following mandatory sections:
- **Resources**: Direct references to AI summaries, meeting transcripts, and recordings.
- **Topics Discussed**: High-level subjects formatted in concise 1-2 sentence bullet points.
- **Decisions**: Explicit policy or technical conclusions reached during the session.
- **Deliverables**: Tangible assets identified or assigned during the meeting.
- **Action Items**: Structured table specifying Task Owner, Description, and Due Date.

Sections lacking discussion or output must explicitly retain their heading and state `None.` rather than being omitted [^evt-ws-taxonomy-landscape-file-eb9c68e792e7-e45bd7ea].

### Indexing Workflow

Upon generating a meeting note, authors must update the repository `README.md` index table [^evt-ws-taxonomy-landscape-file-eb9c68e792e7-e45bd7ea]:
1. Insert a new row immediately below the table header to preserve reverse-chronological order.
2. Include the meeting date, a relative link titled `Full notes`, and a 1-2 sentence overview of the agenda.

### Communication Style Constraints

All notes, commits, pull request narratives, and automated agent interactions must respect explicit stylistic boundaries [^evt-ws-taxonomy-landscape-file-eb9c68e792e7-e45bd7ea]:
- Avoid contrastive language and partial clauses.
- Avoid line breaks using markdown horizontal rules.
- Maintain a direct, neutral voice that balances professional precision with approachable phrasing.
- Omit sycophantic or hollow praise.

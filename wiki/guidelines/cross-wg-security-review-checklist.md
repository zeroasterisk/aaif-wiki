# Overview

The Cross-WG Security and Privacy Review Checklist defines a lightweight assessment instrument and formal review workflow applied by the [../working-groups/security-and-privacy.md](../working-groups/security-and-privacy.md) working group to evaluate deliverables from other AAIF bodies. It operationalizes the Security and Privacy WG's mandate as an intersecting cross-foundation governance layer [^evt-wg-security-and-privacy-file-b0dad759cb11-f74bdc54].

# Architecture / Specification

The review process establishes specific evaluation criteria tailored to the focus areas of incoming specifications and reference architectures [^evt-wg-security-and-privacy-file-b0dad759cb11-f74bdc54]:

- **[../working-groups/identity-and-trust.md](../working-groups/identity-and-trust.md)**: Agent identity verification, delegation limits, and decentralized authorization boundaries.
- **[../working-groups/observability-and-traceability.md](../working-groups/observability-and-traceability.md)**: Behavioral anomaly detection thresholds, audit logging integrity, and trace data privacy.
- **[../working-groups/agentic-commerce.md](../working-groups/agentic-commerce.md)**: Payment security guardrails, containment of fund-draining vulnerabilities, account leakage prevention, and scope constraints on transaction-initiating agents.
- **Emerging AAIF Deliverables**: Standardized review gates assessing attack surface expansion, blast-radius containment, and data sovereignty compliance.

# Lifecycle History

The workstream is led by Govindaraj Palanisamy (Global Payments) with active contributions from representatives across Huawei, JetBrains, Ericsson, SAP, JPMorgan Chase, and IBM [^evt-wg-security-and-privacy-file-b0dad759cb11-f74bdc54].

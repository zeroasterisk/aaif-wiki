# Overview
To be included in the AAIF Agentic AI Landscape, entries must adhere to specific guidelines primarily focused on open source status, community adoption, and relevance to agentic AI [^evt-aaif-landscape-file-b33563055168-4c8ec9d1].

# Architecture / Specification
Key inclusion criteria include:
1. Open source projects generally require at least 1000 GitHub stars and must clearly fit into an existing category.
2. Organizations are generally limited to listing only one major or best-known project.
3. Commercial versions of open source software, closed source products, services, or proprietary standards are not included.
4. Entries require a logo in SVG format, which must include the name in English, and should avoid reversed or overly horizontal layouts.
5. The Crunchbase organization listed should be the entity controlling the software, typically the trademark owner [^evt-aaif-landscape-file-b33563055168-4c8ec9d1].

Submissions are made via pull request to the `landscape.yml` file in the `aaif/aaif-landscape` repository, with the logo added to the `hosted_logos` directory [^evt-aaif-landscape-file-b33563055168-4c8ec9d1].

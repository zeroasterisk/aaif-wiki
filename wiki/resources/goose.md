# Overview
Goose is an open-source autonomous general-purpose AI agent framework designed for local multi-turn execution, automated code development, and extensible tool interaction [^evt-ws-taxonomy-landscape-pr-27]. Donated to the Agentic AI Foundation at launch alongside the Model Context Protocol (MCP), Goose serves as a foundation-hosted project categorized under Autonomous Agent Frameworks in the AAIF landscape [^evt-ws-taxonomy-landscape-pr-27].

# Architecture / Specification
Goose executes autonomously across local development workflows by interfacing with LLMs and local tooling [^evt-ws-taxonomy-landscape-pr-27]. Following its donation from Block, its official governance and repository home transitioned to the AAIF GitHub organization (`github.com/aaif-goose/goose`), with official documentation hosted at `goose-docs.ai` [^evt-ws-taxonomy-landscape-pr-27].

Within the [Agentic AI Landscape](../resources/agentic-ai-landscape.md), Goose is cataloged with `project: member` designation, aligning with the initial foundation intake tier alongside MCP [^evt-ws-taxonomy-landscape-pr-27].

# Lifecycle History
Originally open-sourced as `block/goose`, the project was donated to the Linux Foundation's Agentic AI Foundation upon foundation inception [^evt-ws-taxonomy-landscape-pr-27]. Its placement within the [Taxonomy and Landscape Workstream](../working-groups/taxonomy-and-landscape.md) mapping reflects its role as a flagship autonomous agent framework [^evt-ws-taxonomy-landscape-pr-27].

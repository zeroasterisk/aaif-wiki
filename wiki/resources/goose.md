# Overview
Goose is an open-source general-purpose AI agent framework providing a local multi-turn execution runtime, an extensible tool ecosystem, and autonomous task execution capabilities[^evt-ws-taxonomy-landscape-pr-27]. Donated to the Agentic AI Foundation at launch alongside the Model Context Protocol (MCP), the project is cataloged within the foundation's ecosystem under the Autonomous Agent Frameworks category with member project status[^evt-ws-taxonomy-landscape-pr-27].

# Architecture / Specification
Following its donation to the foundation, Goose transitioned governance and source repository custody to the foundation organization under `github.com/aaif-goose/goose`, with official documentation hosted at `goose-docs.ai`[^evt-ws-taxonomy-landscape-pr-27]. The framework operates as an execution harness enabling agents to plan, execute multi-turn tool workflows, and interact directly across developer environments.

Within the foundation's [Agentic AI Landscape](agentic-ai-landscape.md), Goose is cataloged as a member-tier foundation-hosted project alongside foundational protocol initiatives[^evt-ws-taxonomy-landscape-pr-27].

# Overview
Agentgateway is an open-source traffic mediation and policy enforcement proxy managing Model Context Protocol (MCP) and Agent-to-Agent (A2A) communications, cataloged as an AAIF member project[^evt-aaif-landscape-pr-17].

# Architecture / Specification
Agentgateway mediates communication across heterogeneous agentic interfaces, providing:
- **Protocol Mediation**: Brokering interactions between client agent harnesses and MCP servers.
- **Agent-to-Agent (A2A) Routing**: Facilitating secure message passing and task delegation across independent agent runtimes.
- **Policy Enforcement**: Applying access controls, authentication checks, and traffic governance at the network and protocol boundary.

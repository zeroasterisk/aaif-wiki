# Overview
AgentGateway is an open-source traffic mediation and policy enforcement proxy designed to manage Model Context Protocol (MCP) and agent-to-agent (A2A) communications.[^evt-aaif-landscape-pr-17] Cataloged as an Agentic AI Foundation member project within the [Agentic AI Landscape](../resources/agentic-ai-landscape.md), it acts as an intermediary layer between agents, models, and external tools to govern data flow and enforce runtime boundaries.

# Architecture / Specification
AgentGateway provides protocol-aware routing, authentication, and policy enforcement across heterogeneous agent surfaces. It mediates client-to-agent and tool-to-agent interactions, enabling organizations to inspect, shape, and secure traffic without modifying agent runtime code or downstream endpoints.

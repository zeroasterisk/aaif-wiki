# Overview
The Agentic Use Case Classification and Inventory is an empirical catalog and schema curated by the [Workflows & Process Integration Working Group](../working-groups/workflows-and-process-integration.md) to classify real-world production agentic deployments and identify recurring workflow shapes.[^evt-wg-workflows-and-process-integration-file-5028db4c24a1-b054a303]

# Architecture / Specification
The Critical Use Cases workstream establishes a systematic classification framework and inventory dataset to map deployment choices across industries:[^evt-wg-workflows-and-process-integration-file-5028db4c24a1-b054a303]

- **Schema Definitions (`schema-agentic-use-cases.md`)**: Standardizes column taxonomy, classification dimensions, autonomy tiers, and execution constraints.[^evt-wg-workflows-and-process-integration-file-5028db4c24a1-b054a303]
- **Production Inventory (`use-case-inventory.md`)**: Catalogs named, deployed agentic workflows mapped across classification dimensions to discover structural workflow shapes and pattern frequencies.[^evt-wg-workflows-and-process-integration-file-5028db4c24a1-b054a303]

## Evidentiary Standard
To ensure the catalog reflects genuine production implementations rather than theoretical proposals, the workstream enforces strict citation criteria for inventory rows:[^evt-wg-workflows-and-process-integration-file-5028db4c24a1-b054a303]

1. **Preferred Sources**: Vendor product pages or primary announcements documenting a confirmed, named customer deployment (e.g., enterprise production rollouts).[^evt-wg-workflows-and-process-integration-file-5028db4c24a1-b054a303]
2. **Acceptable Sources**: Vendor product pages detailing verified feature availability operating in production at scale without a named customer.[^evt-wg-workflows-and-process-integration-file-5028db4c24a1-b054a303]
3. **Unacceptable Sources**: Secondary blogs, analyst market projections, academic concept papers, unverified personal knowledge, or unreferenced individual write-ups.[^evt-wg-workflows-and-process-integration-file-5028db4c24a1-b054a303]

Every use case requires at least one verified citation, targeting three independent citations for mature entries.[^evt-wg-workflows-and-process-integration-file-5028db4c24a1-b054a303][^evt-wg-workflows-and-process-integration-pr-46]

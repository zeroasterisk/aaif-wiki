# Overview
The Agentic AI Foundation (AAIF) Code of Conduct establishes standards for fostering an inclusive, welcoming, and safe environment across all Foundation activities[^evt-foundation-file-ffdbe3a1e7ee-0ec44588].

# Architecture / Specification
The Code of Conduct governs participation in AAIF Governing Board meetings, Technical Committee meetings ([`technical-committee`](../governance/technical-committee.md)), Working Group meetings, Outreach Committee meetings, and general Foundation activities not covered by separate project-specific policies[^evt-foundation-file-ffdbe3a1e7ee-0ec44588].

- **Foundation Events**: In-person and virtual events managed with professional event staff fall under the Linux Foundation Events Code of Conduct used in conjunction with this policy[^evt-foundation-file-ffdbe3a1e7ee-0ec44588].
- **Technical Projects**: Umbrella technical projects operate as separate entities and maintain their own distinct codes of conduct for project participants[^evt-foundation-file-ffdbe3a1e7ee-0ec44588].

The policy defines expected behaviors—such as welcoming language, constructive collaboration, and respecting diverse viewpoints—alongside explicit prohibitions against discrimination, harassment, sustained disruption, personal attacks, and unauthorized distribution of private data[^evt-foundation-file-ffdbe3a1e7ee-0ec44588].

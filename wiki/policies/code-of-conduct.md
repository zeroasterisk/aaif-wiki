# Overview
The Agentic AI Foundation (AAIF) Code of Conduct defines the standards of behavior, inclusivity commitments, and enforcement scope for participants across Foundation activities[^evt-foundation-file-ffdbe3a1e7ee-0ec44588].

# Architecture / Specification
## Scope
The Code of Conduct applies directly to Governing Board meetings, Technical Committee meetings, Working Group meetings, Outreach Committee meetings, and other Foundation-wide activities[^evt-foundation-file-ffdbe3a1e7ee-0ec44588].

- **Foundation Events**: In-person and virtual events managed by professional events staff are governed by the Linux Foundation Events Code of Conduct in conjunction with this policy[^evt-foundation-file-ffdbe3a1e7ee-0ec44588].
- **Technical Projects**: Technical projects operating under the AAIF umbrella maintain their own project-specific codes of conduct[^evt-foundation-file-ffdbe3a1e7ee-0ec44588].

## Behavioral Standards
The policy mandates respectful, welcoming, and collaborative conduct while strictly prohibiting harassment, discrimination, sustained disruption, personal attacks, and non-consensual disclosure of private information[^evt-foundation-file-ffdbe3a1e7ee-0ec44588].

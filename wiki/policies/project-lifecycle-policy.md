# Overview

The Project Lifecycle Policy defines the formal process for open technical projects to join the Agentic AI Foundation (AAIF), progress through maturity stages, and undergo annual evaluations [^evt-technical-committee-file-8f732085cd4f-49330cd0]. Managed under the direction of the [Technical Committee](../governance/technical-committee.md), it establishes uniform admission and graduation criteria across all foundation projects [^evt-technical-committee-file-8f732085cd4f-49330cd0].

# Architecture / Specification

## Project Proposal Process

Projects must be submitted through the AAIF project proposals repository with detailed intake metadata, including [^evt-technical-committee-file-8f732085cd4f-49330cd0]:
- Project description, mission alignment, and relationships with existing AAIF projects.
- Example use cases, evidence of adoption, and an identified Technical Committee sponsor.
- OSI-approved permissive licensing, public repository location, automated release processes, and issue tracker.
- Maintainer team structure, governance documentation, and official communication channels.

## Lifecycle Stages

The policy structures project maturity across four discrete stages [^evt-technical-committee-file-8f732085cd4f-49330cd0]:
- **Sandbox Stage**: Entry point for early-stage or experimental open-source efforts requiring incubation and foundation alignment.
- **Growth Stage**: Intermediate stage for projects with active multi-organizational contributor communities and demonstrated adoption.
- **Impact Stage**: Production-grade projects demonstrating widespread ecosystem adoption, sustained governance maturity, and high utility.
- **Emeritus Stage**: Retired or archived projects that are no longer under active development.

## Annual Review Process

All active projects participate in an annual review conducted by the Technical Committee to evaluate project health, community diversity, and stage progression readiness [^evt-technical-committee-file-8f732085cd4f-49330cd0].

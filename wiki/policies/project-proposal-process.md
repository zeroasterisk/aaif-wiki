# Overview
The Project Proposal Process establishes the formal governance workflow and legal conditions required to submit, evaluate, and onboard open-source projects into the Agentic AI Foundation[^evt-foundation-issue-8]. It aligns project intake with the [Technical Committee](../governance/technical-committee.md) review criteria and enforces foundation charter prerequisites[^evt-foundation-issue-8].

# Architecture / Specification
The proposal procedure requires project sponsors to complete a formal submission containing technical documentation, license compliance audits, and governance commitments[^evt-foundation-issue-8].

### Trademark and Account Donation Requirement
Under Section 8 of the AAIF Foundation Charter, applicants submitting projects for foundation hosting must agree that, upon acceptance, all associated project trademarks (including project names) and official administrative accounts (e.g., repository ownership, package registries, and social media) are formally transferred and donated to the AAIF[^evt-foundation-issue-8]. This ensures vendor neutrality, prevents project hijacking, and preserves community governance under Linux Foundation guidelines[^evt-foundation-issue-8].
